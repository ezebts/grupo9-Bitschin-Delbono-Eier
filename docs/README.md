# Design documentation

These folders are the versioned copy of the design. If a diagram or a mockup changes, update the matching file in this directory in the same change. The pull request must include that update so the diff shows what changed.

**IMPORTANT: If any documentation change you need to ensure it's still working/rendering properly.**
